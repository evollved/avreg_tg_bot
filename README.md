# Telegram Bot для Avreg - Система уведомлений о движении

Полноценная система Telegram уведомлений для системы видеонаблюдения Avreg, автоматически отправляющая фото и видео при обнаружении движения.

## 📋 Основные возможности

### 🔔 Уведомления в реальном времени
- Мгновенные уведомления в Telegram при обнаружении движения
- Поддержка отправки фото, видео или обоих форматов
- Настраиваемые текстовые сообщения с временем события

### 🎥 Медиа обработка
- Автоматический захват фото с камер Avreg
- Запись видео с настраиваемой длительностью (5+ секунд)
- Конвертация видео в MP4 через ffmpeg (автоматическое сжатие)
- Поддержка различных форматов отправки (видео/документ)

### ⚙️ Гибкая настройка
- Поддержка нескольких камер (до 20 камер)
- Индивидуальные настройки для каждой камеры:
  - Разные чаты/каналы для каждой камеры
  - Индивидуальные типы медиа (фото/видео/оба)
  - Разная длительность видео
  - Настраиваемый FPS для видео
  - Индивидуальные настройки отправки текста и медиа
- Общие чаты для всех камер

### 🛠️ Автоматизация
- Интеграция с event-collector Avreg
- Автоматический запуск при обнаружении движения
- Фоновая обработка событий
- Автоматическая очистка временных файлов

### 🔒 Безопасность
- Изоляция под пользователем `avreg`
- Защищенные конфигурационные файлы
- Резервное копирование конфигураций
- Проверка доступности всех компонентов

## 🆕 Новые возможности в версии 1.7

### 🌐 Поддержка прокси для Telegram API
- **SOCKS5 прокси** с поддержкой авторизации
- **HTTP/HTTPS прокси** с поддержкой авторизации
- **MTProto прокси** - специализированный прокси для Telegram
- Интерактивная настройка прокси при установке
- Автоматическая проверка и установка зависимостей (`curl` с SOCKS5, `jq`)

### 📱 Гибкая настройка отправки сообщений (из версии 1.5-1.6)
- Три режима отправки:
  - Отправка текста + медиа (полные уведомления)
  - Только медиа (фото/видео без текста) - идеально для тихих чатов
  - Только текст (без медиа) - для экономии трафика
- Индивидуальные настройки для каждой камеры
- Умная обработка: при отправке только медиа подписи автоматически отключаются

### 📁 Отправка сохраненных файлов (версия 1.6)
- Отправка уже сохраненных снимков и видео из архива Avreg
- Интеграция с event-collector для автоматической отправки при сохранении файлов
- Поддержка отправки как снимков (snapshot), так и видео (video)

### 📅 Расширенная система расписания (из версии 1.4)
- Гибкое расписание работы бота: настройка дней недели, часов и минут
- Три режима работы: всегда, общее расписание, индивидуальное для каждой камеры
- Настраиваемые исключения: выходные и праздничные дни
- Автоматическая проверка времени перед отправкой уведомлений

### 🚨 Расширенная система событий
- Поддержка всех типов событий Avreg:
  - Движение (motion) - обнаружение движения
  - Захват видео (capture) - статус захвата видео
  - Ошибки (errors) - критические ошибки системы
  - Запись (recording) - статус записи видео
  - Сохранение файлов (files) - сохранение видео/фото
  - Качество изображения (quality) - изменения качества
  - Сеть (network) - подключение клиентов
- Настраиваемые уровни важности (DEBUG, INFO, WARNING, ERROR, CRITICAL)
- Отдельные настройки событий для каждой камеры

## ⚙️ Конфигурация

### Основные параметры
- `BOT_TOKEN` - токен вашего Telegram бота
- `AVREG_URL` - адрес сервера Avreg (по умолчанию: localhost)
- Логин/пароль - учетные данные Avreg
- Количество камер - от 1 до 20 камер

### Настройки прокси (новое в версии 1.7)
- `PROXY_TYPE` - тип прокси (none/socks5/http/mtproto)
- `PROXY_HOST` - хост прокси
- `PROXY_PORT` - порт прокси
- `PROXY_USER` - логин для авторизации (опционально)
- `PROXY_PASS` - пароль для авторизации (опционально)
- `PROXY_MT_PROTO` - флаг MTProto (true/false)
- `PROXY_MT_SECRET` - секрет для MTProto (опционально)

### Настройки отправки сообщений
- `SEND_TEXT` - отправлять текстовые уведомления (true/false)
- `SEND_MEDIA` - отправлять медиафайлы (true/false)

| SEND_TEXT | SEND_MEDIA | Результат |
|-----------|------------|-----------|
| true | true | Полные уведомления (текст + фото/видео) |
| false | true | Только медиа (фото/видео без подписей) |
| true | false | Только текст (без фото/видео) |
| false | false | Отключено (не используется) |

### Настройки расписания
- `SCHEDULE_ENABLED` - включить/выключить расписание (true/false)
- `SCHEDULE_TYPE` - тип расписания (always/custom)
- `SCHEDULE_DAYS` - дни недели (0-6, где 0=воскресенье)
- `SCHEDULE_HOURS` - часы работы (0-23, можно диапазоны 8-20)
- `SCHEDULE_MINUTES` - минуты (0-59, можно 0,15,30,45)
- `SCHEDULE_EXCLUDE_DATES` - исключенные даты (ГГГГ-ММ-ДД)
- `SEND_CRITICAL_ALWAYS` - отправлять критические ошибки всегда (true/false)

### Настройки событий
- `EVENT_TYPES` - типы отправляемых событий (motion, capture, errors, recording, files, quality, network, all, motion_only)
- `LOG_LEVEL` - минимальный уровень важности для отправки (DEBUG, INFO, WARNING, ERROR, CRITICAL)

### Настройки для каждой камеры
- **Номер камеры** в базе Avreg (обычно 1, 2, 3...)
- **Chat ID** - ID чата/канала для уведомлений
- **Настройки отправки**:
  - `GENERAL` - использовать общие настройки
  - Индивидуальные: можно переопределить `SEND_TEXT` и `SEND_MEDIA`
- **Тип медиа**:
  - `photo` - только фото
  - `video` - только видео
  - `both` - фото и видео
- **Типы событий** для камеры (GENERAL/индивидуальные)
- **Расписание** для камеры (GENERAL/ALWAYS/индивидуальное)
- **Длительность видео** (в секундах, минимум 5)
- **FPS видео** (1-30, по умолчанию 5)

## 🔧 Интеграция с Avreg
Скрипт автоматически модифицирует `event-collector` Avreg:
- Добавляет обработку всех типов событий Avreg
- Автоматически запускает `tg.sh` при событиях
- Поддерживает несколько камер с индивидуальными настройками
- Интегрируется с системой расписания


## ⚠️ Решение проблем

### Проблема: Бот не отправляет сообщения
- Проверьте токен бота: `echo $BOT_TOKEN`
- Убедитесь, что бот добавлен в чат
- Для каналов: бот должен быть администратором
- Проверьте Chat ID (отрицательный для групп/каналов)
- Проверьте расписание: `sudo -u avreg /etc/avreg/scripts/tg.sh schedule`
- Проверьте настройки отправки текста/медиа в конфигурации
- Проверьте настройки прокси (если используется)

### Проблема: Не работают уведомления через прокси
- Проверьте доступность прокси: `curl -x socks5://proxy:1080 https://api.telegram.org`
- Убедитесь, что curl собран с поддержкой SOCKS5: `curl --version | grep socks`
- Проверьте логи на наличие ошибок подключения
- Проверьте правильность введенных данных (хост, порт, логин/пароль)

### Проблема: Не отправляются фото, но текст приходит
- Проверьте настройку `SEND_MEDIA` (должна быть true)
- Проверьте индивидуальные настройки камеры
- Проверьте тип медиа для камеры (photo/both)
- Проверьте логи на наличие ошибок получения фото

### Проблема: Не отправляется текст, но медиа приходит
- Проверьте настройку `SEND_TEXT` (должна быть true)
- Проверьте индивидуальные настройки камеры
- В версии 1.5+ это нормальное поведение для режима "только медиа"

### Проблема: Не получается получить изображение
- Проверьте доступность Avreg: `curl http://localhost:874`
- Проверьте номер камеры в базе Avreg
- Проверьте логи авторизации
- Проверьте права доступа пользователя avreg

### Проблема: Большой размер видео
- Установите ffmpeg для автоматического сжатия
- Уменьшите длительность видео
- Уменьшите FPS (рекомендуется 5-10)
- Установите через меню: пункт 9

### Проблема: Не работают определенные типы событий
- Проверьте настройки событий в конфигурации
- Убедитесь, что event-collector модифицирован
- Проверьте уровни логирования
- Протестируйте конкретное событие через команду test

## 📝 Примечания

### Рекомендации по настройке прокси
- **SOCKS5** - рекомендуется для обхода сетевых ограничений
- **HTTP/HTTPS** - для работы через корпоративные прокси
- **MTProto** - специализированный протокол Telegram для максимальной совместимости
- Убедитесь, что прокси сервер доступен с сервера Avreg
- Для SOCKS5 требуется curl с поддержкой этого протокола

### Рекомендации по настройке отправки сообщений
- **Режим "только медиа"** идеален для:
  - Каналов с автоматической публикацией
  - Ситуаций, где важны только фото/видео
  - Экономии места в ленте сообщений
- **Режим "только текст"** полезен для:
  - Мониторинга статуса системы
  - Уведомлений об ошибках
  - Медленных интернет-соединений
- **Индивидуальные настройки** позволяют:
  - Настроить разные режимы для разных камер
  - Постепенно внедрять изменения

### Рекомендации по расписанию
- Используйте диапазоны часов для удобства (например, 8-20 для рабочего времени)
- Для ночного режима используйте обратный диапазон (20-8)
- Настройте исключения для праздничных дней
- Для критически важных камер используйте режим ALWAYS

### Оптимизация видео
- Рекомендуемый FPS: 5-10 кадров/сек для баланса качества и размера
- Рекомендуемая длительность: 10-15 секунд
- Обязательно установите ffmpeg для конвертации в MP4
- Используйте мониторинг размера файлов в логах

### Безопасность
- Храните конфигурационные файлы с ограниченными правами
- Используйте отдельного пользователя для запуска скриптов
- Регулярно обновляйте зависимости
- Настройте резервное копирование конфигураций

### Производительность
- Система оптимизирована для работы с 1-10 камерами
- Для большего количества камер настройте индивидуальные расписания
- Мониторьте использование диска в /tmp/avreg_telegram
- Регулярно проверяйте логи на наличие ошибок

**Основные улучшения версии 1.7:** поддержка прокси (SOCKS5, HTTP/HTTPS, MTProto)  
**Основные улучшения версии 1.6:** отправка сохраненных файлов из архива Avreg  
**Основные улучшения версии 1.5:** гибкая настройка отправки текста/медиа, индивидуальные настройки для камер  
**Основные улучшения версии 1.4:** система расписания, поддержка всех событий Avreg, улучшенное управление конфигурацией
