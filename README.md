# Telegram Bot для Avreg - Система уведомлений о движении

Полноценная система Telegram уведомлений для системы видеонаблюдения Avreg, автоматически отправляющая фото и видео при обнаружении движения.

## 📋 Основные возможности

### 🔔 Уведомления в реальном времени
- Мгновенные уведомления в Telegram при обнаружении движения
- Поддержка отправки фото, видео или обоих форматов
- Настраиваемые текстовые сообщения с временем события

### 🎥 Медиа обработка
- **Автоматический захват фото** с камер Avreg
- **Запись видео** с настраиваемой длительностью (5+ секунд)
- **Конвертация видео** в MP4 через ffmpeg (автоматическое сжатие)
- Поддержка различных форматов отправки (видео/документ)

### ⚙️ Гибкая настройка
- **Поддержка нескольких камер** (до 20 камер)
- **Индивидуальные настройки** для каждой камеры:
  - Разные чаты/каналы для каждой камеры
  - Индивидуальные типы медиа (фото/видео/оба)
  - Разная длительность видео
  - Настраиваемый FPS для видео
  - Индивидуальные настройки отправки текста и медиа
- **Общие чаты** для всех камер

### 🛠️ Автоматизация
- **Интеграция с event-collector** Avreg
- Автоматический запуск при обнаружении движения
- Фоновая обработка событий
- Автоматическая очистка временных файлов

### 🔒 Безопасность
- Изоляция под пользователем `avreg`
- Защищенные конфигурационные файлы
- Резервное копирование конфигураций
- Проверка доступности всех компонентов

## 🚀 Быстрый старт

- Установленная система видеонаблюдения Avreg
- Telegram бот (создать через [@BotFather](https://t.me/botfather))
- Bash, curl, wget, base64 (автоматически проверяются)

### 2. Установка
```bash
# Клонирование или копирование скрипта

# Запуск установщика
```

5. **Показать текущую конфигурацию** - просмотр настроек

8. **Перезапустить avreg** - применение изменений
9. **Проверить/установить ffmpeg** - оптимизация видео
10. **Запустить редактор конфигурации** - изменение настроек

## ⚙️ Конфигурация

### Основные параметры
- **BOT_TOKEN** - токен вашего Telegram бота
- **AVREG_URL** - адрес сервера Avreg (по умолчанию: localhost)
- **Логин/пароль** - учетные данные Avreg
- **Количество камер** - от 1 до 20 камер

### Настройки отправки сообщений (новое в версии 1.5)
- **SEND_TEXT** - отправлять текстовые уведомления (true/false)
- **SEND_MEDIA** - отправлять медиафайлы (true/false)

**Варианты комбинаций:**
| SEND_TEXT | SEND_MEDIA | Результат |
|-----------|------------|-----------|
| true      | true       | Полные уведомления (текст + фото/видео) |
| false     | true       | Только медиа (фото/видео без подписей) |
| true      | false      | Только текст (без фото/видео) |
| false     | false      | Отключено (не используется) |

### Настройки расписания
- **SCHEDULE_ENABLED** - включить/выключить расписание (true/false)
- **SCHEDULE_TYPE** - тип расписания (always/custom)
- **SCHEDULE_DAYS** - дни недели (0-6, где 0=воскресенье)
- **SCHEDULE_HOURS** - часы работы (0-23, можно диапазоны 8-20)
- **SCHEDULE_MINUTES** - минуты (0-59, можно 0,15,30,45)
- **SCHEDULE_EXCLUDE_DATES** - исключенные даты (ГГГГ-ММ-ДД)
- **SEND_CRITICAL_ALWAYS** - отправлять критические ошибки всегда (true/false)

### Настройки событий
- **EVENT_TYPES** - типы отправляемых событий (motion, capture, errors, recording, files, quality, network, all, motion_only)
- **LOG_LEVEL** - минимальный уровень важности для отправки (DEBUG, INFO, WARNING, ERROR, CRITICAL)

### Настройки для каждой камеры
1. **Номер камеры в базе Avreg** (обычно 1, 2, 3...)
2. **Chat ID** - ID чата/канала для уведомлений
3. **Настройки отправки** (новое в версии 1.5):
   - `GENERAL` - использовать общие настройки
   - Индивидуальные: можно переопределить `SEND_TEXT` и `SEND_MEDIA`
4. **Тип медиа**:
   - `photo` - только фото
   - `video` - только видео  
   - `both` - фото и видео
5. **Типы событий** для камеры (GENERAL/индивидуальные)
6. **Расписание** для камеры (GENERAL/ALWAYS/индивидуальное)
7. **Длительность видео** (в секундах, минимум 5)
8. **FPS видео** (1-30, по умолчанию 5)

## 🔧 Интеграция с Avreg

Скрипт автоматически модифицирует `event-collector` Avreg:
- Добавляет обработку всех типов событий Avreg
- Автоматически запускает `tg.sh` при событиях
- Поддерживает несколько камер с индивидуальными настройками
- Интегрируется с системой расписания

## ⚠️ Решение проблем

### Проблема: Бот не отправляет сообщения
1. Проверьте токен бота: `echo $BOT_TOKEN`
2. Убедитесь, что бот добавлен в чат
3. Для каналов: бот должен быть администратором
4. Проверьте Chat ID (отрицательный для групп/каналов)
5. Проверьте расписание: `sudo -u avreg /etc/avreg/scripts/tg.sh schedule`
6. **Новое**: Проверьте настройки отправки текста/медиа в конфигурации

### Проблема: Не отправляются фото, но текст приходит
1. Проверьте настройку `SEND_MEDIA` (должна быть true)
2. Проверьте индивидуальные настройки камеры
3. Проверьте тип медиа для камеры (photo/both)
4. Проверьте логи на наличие ошибок получения фото

### Проблема: Не отправляется текст, но медиа приходит
1. Проверьте настройку `SEND_TEXT` (должна быть true)
2. Проверьте индивидуальные настройки камеры
3. В версии 1.5 это нормальное поведение для режима "только медиа"

### Проблема: Не получается получить изображение
1. Проверьте доступность Avreg: `curl http://localhost:874`
2. Проверьте номер камеры в базе Avreg
3. Проверьте логи авторизации
4. Проверьте права доступа пользователя avreg

### Проблема: Большой размер видео
1. Установите ffmpeg для автоматического сжатия
2. Уменьшите длительность видео
3. Уменьшите FPS (рекомендуется 5-10)
4. Установите через меню: пункт 9

### Проблема: Не работают определенные типы событий
1. Проверьте настройки событий в конфигурации
2. Убедитесь, что event-collector модифицирован
3. Проверьте уровни логирования
4. Протестируйте конкретное событие через команду test

## 🔄 Обновление

### Обновление с версии 1.4 до 1.5
1. Создайте резервную копию конфигурации:
```bash
sudo cp /etc/avreg/scripts/telegram_config.sh /etc/avreg/scripts/telegram_config.sh.backup
```

2. Запустите установщик и выберите пункт 1 для настройки конфигурации

3. При настройке появится новый вопрос о режиме отправки сообщений:
   - "Отправлять текстовые уведомления вместе с медиа?"
   - Выберите нужный режим (текст+медиа / только медиа / только текст)

4. После настройки проверьте работу:
```bash
sudo -u avreg /etc/avreg/scripts/tg.sh test 1
```

### Полное обновление
```bash
sudo cp /etc/avreg/scripts/telegram_config.sh /etc/avreg/scripts/telegram_config.sh.backup
sudo /tmp/Avreg_tg_bot_installer.sh
# Выберите пункт 1 для перенастройки
```

## 📝 Примечания

### Рекомендации по настройке отправки сообщений
- **Режим "только медиа"** идеален для:
  - Каналов с автоматической публикацией
  - Ситуаций, где важны только фото/видео
  - Экономии места в ленте сообщений
- **Режим "только текст"** полезен для:
  - Мониторинга статуса системы
  - Уведомлений об ошибках
  - Медленных интернет-соединений
- **Индивидуальные настройки** позволяют:
  - Настроить разные режимы для разных камер
  - Постепенно внедрять изменения

### Рекомендации по расписанию
- Используйте диапазоны часов для удобства (например, 8-20 для рабочего времени)
- Для ночного режима используйте обратный диапазон (20-8)
- Настройте исключения для праздничных дней
- Для критически важных камер используйте режим ALWAYS

### Оптимизация видео
- **Рекомендуемый FPS**: 5-10 кадров/сек для баланса качества и размера
- **Рекомендуемая длительность**: 10-15 секунд
- **Обязательно установите ffmpeg** для конвертации в MP4
- Используйте мониторинг размера файлов в логах

### Безопасность
- Храните конфигурационные файлы с ограниченными правами
- Используйте отдельного пользователя для запуска скриптов
- Регулярно обновляйте зависимости
- Настройте резервное копирование конфигураций

### Производительность
- Система оптимизирована для работы с 1-10 камерами
- Для большего количества камер настройте индивидуальные расписания
- Мониторьте использование диска в /tmp/avreg_telegram
- Регулярно проверяйте логи на наличие ошибок

Полноценная система Telegram уведомлений для системы видеонаблюдения Avreg, автоматически отправляющая фото и видео при обнаружении движения.

### 🔔 Уведомления в реальном времени

- Настраиваемые текстовые сообщения с временем события

- **Автоматический захват фото** с камер Avreg
- **Запись видео** с настраиваемой длительностью (5+ секунд)
- **Конвертация видео** в MP4 через ffmpeg (автоматическое сжатие)
- Поддержка различных форматов отправки (видео/документ)

## ⚙️ Конфигурация

### Основные параметры
- **BOT_TOKEN** - токен вашего Telegram бота
- **AVREG_URL** - адрес сервера Avreg (по умолчанию: localhost)
- **Логин/пароль** - учетные данные Avreg
- **Количество камер** - от 1 до 20 камер

### Настройки отправки сообщений (новое в версии 1.5)
- **SEND_TEXT** - отправлять текстовые уведомления (true/false)
- **SEND_MEDIA** - отправлять медиафайлы (true/false)

**Варианты комбинаций:**
| SEND_TEXT | SEND_MEDIA | Результат |
|-----------|------------|-----------|
| true      | true       | Полные уведомления (текст + фото/видео) |
| false     | true       | Только медиа (фото/видео без подписей) |
| true      | false      | Только текст (без фото/видео) |
| false     | false      | Отключено (не используется) |

### Настройки расписания
- **SCHEDULE_ENABLED** - включить/выключить расписание (true/false)
- **SCHEDULE_TYPE** - тип расписания (always/custom)
- **SCHEDULE_DAYS** - дни недели (0-6, где 0=воскресенье)
- **SCHEDULE_HOURS** - часы работы (0-23, можно диапазоны 8-20)
- **SCHEDULE_MINUTES** - минуты (0-59, можно 0,15,30,45)
- **SCHEDULE_EXCLUDE_DATES** - исключенные даты (ГГГГ-ММ-ДД)
- **SEND_CRITICAL_ALWAYS** - отправлять критические ошибки всегда (true/false)

### Настройки событий
- **EVENT_TYPES** - типы отправляемых событий (motion, capture, errors, recording, files, quality, network, all, motion_only)
- **LOG_LEVEL** - минимальный уровень важности для отправки (DEBUG, INFO, WARNING, ERROR, CRITICAL)

### Настройки для каждой камеры
1. **Номер камеры в базе Avreg** (обычно 1, 2, 3...)
2. **Chat ID** - ID чата/канала для уведомлений
3. **Настройки отправки** (новое в версии 1.5):
   - `GENERAL` - использовать общие настройки
   - Индивидуальные: можно переопределить `SEND_TEXT` и `SEND_MEDIA`
4. **Тип медиа**:
   - `photo` - только фото
   - `video` - только видео  
   - `both` - фото и видео
5. **Типы событий** для камеры (GENERAL/индивидуальные)
6. **Расписание** для камеры (GENERAL/ALWAYS/индивидуальное)
7. **Длительность видео** (в секундах, минимум 5)
8. **FPS видео** (1-30, по умолчанию 5)

## 🔧 Интеграция с Avreg

Скрипт автоматически модифицирует `event-collector` Avreg:
- Добавляет обработку всех типов событий Avreg
- Автоматически запускает `tg.sh` при событиях
- Поддерживает несколько камер с индивидуальными настройками
- Интегрируется с системой расписания

## ⚠️ Решение проблем

### Проблема: Бот не отправляет сообщения
1. Проверьте токен бота: `echo $BOT_TOKEN`
2. Убедитесь, что бот добавлен в чат
3. Для каналов: бот должен быть администратором
4. Проверьте Chat ID (отрицательный для групп/каналов)
5. Проверьте расписание: `sudo -u avreg /etc/avreg/scripts/tg.sh schedule`
6. **Новое**: Проверьте настройки отправки текста/медиа в конфигурации

### Проблема: Не отправляются фото, но текст приходит
1. Проверьте настройку `SEND_MEDIA` (должна быть true)
2. Проверьте индивидуальные настройки камеры
3. Проверьте тип медиа для камеры (photo/both)
4. Проверьте логи на наличие ошибок получения фото

### Проблема: Не отправляется текст, но медиа приходит
1. Проверьте настройку `SEND_TEXT` (должна быть true)
2. Проверьте индивидуальные настройки камеры
3. В версии 1.5 это нормальное поведение для режима "только медиа"

### Проблема: Не получается получить изображение
1. Проверьте доступность Avreg: `curl http://localhost:874`
2. Проверьте номер камеры в базе Avreg
3. Проверьте логи авторизации
4. Проверьте права доступа пользователя avreg

### Проблема: Большой размер видео
1. Установите ffmpeg для автоматического сжатия
2. Уменьшите длительность видео
3. Уменьшите FPS (рекомендуется 5-10)
4. Установите через меню: пункт 9

### Проблема: Не работают определенные типы событий
1. Проверьте настройки событий в конфигурации
2. Убедитесь, что event-collector модифицирован
3. Проверьте уровни логирования
4. Протестируйте конкретное событие через команду test
