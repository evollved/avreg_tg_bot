# Telegram Bot для Avreg - Система уведомлений о движении

Полноценная система Telegram уведомлений для системы видеонаблюдения Avreg, автоматически отправляющая фото и видео при обнаружении движения.

## 📋 Основные возможности

### 🔔 Уведомления в реальном времени
- Мгновенные уведомления в Telegram при обнаружении движения
- Поддержка отправки фото, видео или обоих форматов
- Настраиваемые текстовые сообщения с временем события

### 🎥 Медиа обработка
- **Автоматический захват фото** с камер Avreg
- **Запись видео** с настраиваемой длительностью (5+ секунд)
- **Конвертация видео** в MP4 через ffmpeg (автоматическое сжатие)
- Поддержка различных форматов отправки (видео/документ)

### ⚙️ Гибкая настройка
- **Поддержка нескольких камер** (до 20 камер)
- **Индивидуальные настройки** для каждой камеры:
  - Разные чаты/каналы для каждой камеры
  - Индивидуальные типы медиа (фото/видео/оба)
  - Разная длительность видео
  - Настраиваемый FPS для видео
- **Общие чаты** для всех камер

### 🛠️ Автоматизация
- **Интеграция с event-collector** Avreg
- Автоматический запуск при обнаружении движения
- Фоновая обработка событий
- Автоматическая очистка временных файлов

### 🔒 Безопасность
- Изоляция под пользователем `avreg`
- Защищенные конфигурационные файлы
- Резервное копирование конфигураций
- Проверка доступности всех компонентов

## 📁 Структура проекта

```
/etc/avreg/scripts/
├── tg.sh                    # Основной скрипт обработки событий
├── telegram_config.sh       # Конфигурационный файл
├── edit_telegram_config.sh  # Редактор конфигурации
├── event-collector          # Модифицированный обработчик событий
└── backups/                 # Резервные копии конфигураций
```

## 🚀 Быстрый старт

### 1. Предварительные требования
- Установленная система видеонаблюдения Avreg
- Telegram бот (создать через [@BotFather](https://t.me/botfather))
- Bash, curl, wget, base64 (автоматически проверяются)

### 2. Установка
```bash
# Клонирование или копирование скрипта
sudo cp Avreg_tg_bot_installer.sh /tmp/
sudo chmod +x /tmp/Avreg_tg_bot_installer.sh

# Запуск установщика
sudo /tmp/Avreg_tg_bot_installer.sh
```

### 3. Настройка через интерактивное меню
Установщик предоставляет пошаговое меню:

1. **Настроить конфигурацию** - основной шаг настройки
2. **Протестировать конфигурацию** - проверка работы
3. **Настроить event-collector** - интеграция с Avreg
4. **Настроить права доступа** - настройка безопасности
5. **Проверить состояние системы** - диагностика

## ⚙️ Конфигурация

### Основные параметры
- **BOT_TOKEN** - токен вашего Telegram бота
- **AVREG_URL** - адрес сервера Avreg (по умолчанию: localhost)
- **Логин/пароль** - учетные данные Avreg
- **Количество камер** - от 1 до 20 камер

### Настройки для каждой камеры
1. **Номер камеры в базе Avreg** (обычно 1, 2, 3...)
2. **Chat ID** - ID чата/канала для уведомлений
3. **Тип медиа**:
   - `photo` - только фото
   - `video` - только видео  
   - `both` - фото и видео
4. **Длительность видео** (в секундах, минимум 5)
5. **FPS видео** (1-30, по умолчанию 5)

## 🔧 Интеграция с Avreg

Скрипт автоматически модифицирует `event-collector` Avreg:
- Добавляет обработку событий движения
- Автоматически запускает `tg.sh` при обнаружении движения
- Поддерживает несколько камер с индивидуальными настройками


Доступные действия:
- Изменение токена бота
- Редактирование чатов для камер
- Изменение типа медиа
- Настройка параметров видео
- Создание резервных копий

### Проверка состояния
```bash
# Проверить работу бота

# Проверить доступность Avreg

```

## ⚠️ Решение проблем

### Проблема: Бот не отправляет сообщения
1. Проверьте токен бота: `echo $BOT_TOKEN`
2. Убедитесь, что бот добавлен в чат
3. Для каналов: бот должен быть администратором
4. Проверьте Chat ID (отрицательный для групп/каналов)

### Проблема: Не получается получить изображение
1. Проверьте доступность Avreg: `curl http://localhost:874`
2. Проверьте номер камеры в базе Avreg
3. Проверьте логи авторизации

### Проблема: Большой размер видео
1. Установите ffmpeg для автоматического сжатия
2. Уменьшите длительность видео
3. Уменьшите FPS (рекомендуется 5-10)

## 🔄 Обновление

1. Создайте резервную копию конфигурации:
```bash
sudo cp /etc/avreg/scripts/telegram_config.sh /etc/avreg/scripts/telegram_config.sh.backup
```

2. Обновите скрипты через установщик

## 📝 Примечания

### Рекомендации
- **Установите ffmpeg** для лучшей работы с видео
- Используйте отдельный бот для системы видеонаблюдения
- Для каналов используйте публичные или приватные каналы (бот должен быть администратором)
- Регулярно проверяйте логи системы

### Ограничения
- Telegram имеет ограничения на размер файлов (до 50MB)
- Avreg должен быть доступен по сети
- Для работы нужен стабильный интернет

### Безопасность
- Храните конфигурационные файлы с ограниченными правами
- Используйте отдельного пользователя для запуска скриптов
- Регулярно обновляйте зависимости
